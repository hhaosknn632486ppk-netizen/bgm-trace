# Interpreting evidence

- Source separation estimates vocals; subtracting that estimate preserves much of the accompaniment but may leave speech/effects or remove musical detail. A speech detector's silence decision is not a listening review.
- Shazam fingerprints identify catalog recordings, including recordings containing sampled dialogue. Inspect the requested layer. Repeated independent windows increase support, but the same mistaken layer can repeat.
- `candidate_consensus` means at least two non-overlapping positions support one candidate; it is not a proof of title, authorship, licensing, or canonical release. `multiple_candidates` can describe music changes rather than a tool failure.
- Default reference checking bandpasses audio, searches playback-rate changes, and normalizes sliding waveform correlation. Separate query windows must agree on reference positions. This works best on the same master. Equalization, separation damage, repeating music, speed changes that preserve pitch, covers and edits complicate interpretation.
- Pass thresholds are heuristics: at least two windows, each absolute NCC ≥ 0.12 and peak/p99 ≥ 1.5; median NCC ≥ 0.20; inferred base offsets span ≤ 0.15 seconds. A second joint placement over one second away with at least 95% of the best joint score marks timing as ambiguous and prevents a pass. These are observable checks, not statistical confidence calibration. Short windows guide coarse speed search; longer windows are used during refinement and the final decision. Broader validation is required before making accuracy claims.
- Provider errors and rate limits are not negative identification evidence. A rate limit stops subsequent requests in that job. Retain the local artifacts and report the interruption instead of repeatedly submitting more windows.
- The default rate search is 0.94–1.06. Widen it explicitly with `--speed-min` and `--speed-max` when warranted; the CLI accepts 0.5–2.0. This does not independently search pitch and tempo.
- `export-reference` uses a local hash-bound reference, verifies interval coverage, and writes a provenance sidecar. It does not download a master or convert a lossy source into genuinely higher-quality audio.
- Reports omit absolute input paths and signed CDN parameters. They still include names, titles and IDs; review before sharing. Keep audio jobs out of the published skill/repository.
